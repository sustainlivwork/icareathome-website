Project Structure

Care@Home is structured into six interconnected Work Packages (WPs), covering monitoring, technology development, AI, validation, and project management.

Timeline Overview

Duration: 36 months (M1–M36)

Work Packages

WP1

Identification of Critical Monitoring Parameters

Lead: Lithuanian University of Health Sciences

Define key physical activities, vital signs, daily routines (ADLs), and environmental factors that reflect health and independence.

WP2

Contactless IoT System Development

Lead: Tampere University

Develop a non-invasive IoT infrastructure using Nearable & Airable Smart Sensors (NASS) for continuous data collection.

WP3

Localized Sensitive Data Processing (TinyML)

Lead: Tallinn University of Technology

Develop privacy-preserving AI models using TinyML for real-time, local data processing on edge devices.

WP4

AI-Based Monitoring Ecosystem

Lead: Kaunas University of Technology

Integrate system components into a complete AI-powered monitoring ecosystem and validate performance under controlled conditions.

WP5

System Evaluation & Validation

Lead: Jagiellonian University

Evaluate system performance across diverse populations, including nursing homes and private households in multiple countries.

WP6

Project Management & Communication

Lead: Kaunas University of Technology

Ensure coordination, quality assurance, ethical compliance, and dissemination of project results across stakeholders.

How It All Connects

WP1 → WP2

Define what to monitor → build sensing infrastructure

WP2 → WP3 → WP4

Collect data → process locally → integrate into full system

WP4 → WP5

Deploy system → evaluate in real-world environments

Expected Outcomes

AI Monitoring System

Fully functional, privacy-preserving ecosystem

IoT Sensor Network

Contactless and energy-efficient monitoring

Validated Solution

Tested across real users and environments
