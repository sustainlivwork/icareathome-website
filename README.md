# Care@Home Website

A static website presenting the **Care@Home** project, a Horizon Europe-funded research initiative focused on AI-powered, contactless monitoring technologies that support independent living for older adults.

This repository contains the source code for the project's public website, hosted with **GitHub Pages**.

## About the Project

**Care@Home – AI that Cares for Aging at Home** aims to develop an AI-based, privacy-preserving monitoring ecosystem that enables older adults to live independently for longer while supporting caregivers, families, and healthcare professionals.

The project combines:

* Contactless monitoring technologies
* AI-based early risk detection
* TinyML edge processing
* Privacy-preserving data analysis
* IoT sensor networks
* Clinical validation across multiple European countries

The system is designed to improve quality of life, facilitate telecare, and reduce the workload on healthcare providers without replacing human care.
